# 法務省 地図XML（公図）ビューア

> [!NOTE]
> 本プロジェクトのコードおよびアーキテクチャ設計は、主にAIコーディングアシスタントとのペアプログラミングによって構築されました。

ブラウザ上で法務省の地図XML（公図データ）を超高速かつシームレスに閲覧できるウェブアプリケーションです。
独自の前処理プログラムにより、重いXMLデータを極小の適応型四分木（Adaptive Quadtree）ベクトルタイルに変換し、フロントエンドでの圧倒的な描画パフォーマンスを実現しています。

## 🌟 主な特徴

* **シームレスな広域表示**
  * 県境や市区町村境など複数のXMLファイルにまたがる筆（土地）を、境界を意識することなく1枚の地図としてシームレスに描画します。
* **爆速なCanvasレンダリング**
  * フロントエンドでの重いXMLパース処理を排除。事前計算された最小限の頂点データ（JSON）だけを非同期に fetch し、HTML5 Canvas で高速描画します。
  * 画面内に見えている筆数（1万筆以下）に応じた賢い表示制限ロジックを搭載し、ブラウザのフリーズを完全に防ぎます。
* **属性情報のレイジーロード（遅延読み込み）**
  * 描画用のタイルには表示用テキスト（地番）とポリゴン頂点のみを持たせ、ユーザーがクリックした瞬間に元のXMLをバックグラウンドで解析。所有者や精度、縮尺などの詳細情報を瞬時にポップアップ表示します。
* **任意座標系・公共座標系のハイブリッド対応**
  * 公共座標系の筆はズームと同時に自動表示。任意座標系の筆は、逆ジオコーディングとインデックスを活用して目的の場所付近の図面を瞬時に画面下部のステータスバーへリストアップします。
* **国土地理院タイルとの完全な互換性**
  * Sllipy Map タイル（Z/X/Y）の規格に準拠しているため、背景の国土地理院地図（標準地図、航空写真など）と寸分の狂いもなくピッタリと重なります。

## 🚀 使い方

### 1. データの準備（前処理）

法務省からダウンロードしたZIPファイル群（例: `13104-1.zip`）を `public/data/` フォルダ内に配置し、Pythonスクリプトを実行してタイルデータを生成します。

```bash
cd /workspace/kouzufrommap
python3 preprocess_quadtree.py
```

**【処理内容】**
* 全ZIPファイルから公共座標系のXMLを抽出し、緯度経度（EPSG:4326）へ一括変換。
* 密度に応じたQuadtree（Z=12〜16）へ筆データを分割・配置。
* `public/data/tiles/` ディレクトリに極小JSONタイルを保存し、`public_quadtree_index.json` を生成します。

### 2. サーバーの起動

本システムでは、詳細情報を取得する際に「HTTP Rangeリクエスト」を用いてZIPファイルの一部だけを高効率にダウンロードします。そのため、Rangeリクエストに対応した専用のローカルサーバー（`server.py`）を使用してください。

```bash
cd /workspace/kouzufrommap
python3 server.py
```
ブラウザで `http://localhost:8000` にアクセスしてください。

## 📁 ディレクトリ構成

* `public/` : フロントエンド一式（公開用ディレクトリ）
  * `index.html` : メイン画面
  * `css/style.css` : UIのスタイリング
  * `js/`
    * `app.js` : アプリケーションのベースロジック、任意座標系の処理、詳細パネル制御
    * `slippy_map.js` : Canvasベースの独自タイルマップエンジン、Quadtree動的ロード制御
  * `data/` : 前処理済みのJSONタイルやインデックスファイル群
* `preprocess_quadtree.py` : バックエンドの前処理プログラム（適応型四分木タイルの生成）

## ⚙️ 技術スタック

* **フロントエンド**: HTML5, Vanilla JavaScript, Canvas API
* **バックエンド（前処理）**: Python 3, `pyproj` (座標系変換), `xml.etree.ElementTree`
* **外部API/ライブラリ**: 
  * [Proj4js](https://github.com/proj4js/proj4js) (フロントエンドでの座標変換)
  * 国土地理院 API (逆ジオコーディング、住所検索、背景地図タイル)

## 💡 今後の拡張に向けたTips（全国データの処理）

全国規模のデータを前処理する際は、`preprocess_quadtree.py` の実行を都道府県や市区町村ごとに別々に回すと、県境のタイル（`Z/X/Y.json`）が上書きされてしまう可能性があります。
全国分を統合する場合は、「一旦全筆のデータを中間DBに保存してから最後に一括でタイル生成する」か、「既存タイルを読み込んで結合（Merge）してから保存する」ようにスクリプトを拡張することをおすすめします（本システムでは同一IDによる上書きで冪等性を担保する仕組みを前提としています）。
